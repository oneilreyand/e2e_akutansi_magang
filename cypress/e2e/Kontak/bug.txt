3. ketika berada di halaman detail kontak, url langsung mengandung id data (/admin/contacts/idData). sebaiknya juga menambahkan detail (/admin/contacts/detail/idData)

4. pada halaman detail kontak, data pada UI dan response API berbeda. jika pengguna membuat kontak dengan nama ("Akun Nyoba Doang ") dan menyimpannya maka pada UI spasi akan dihapus sedangkan response akan tetap sama dengan data yang diinput.
